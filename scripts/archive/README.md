This directory holds stale one-shot diagnostic and iteration scripts that were
written for a specific calibration wave or investigation and are no longer part
of the active workflow. Nothing in this directory is imported by any live code,
referenced by any current procedure document, or listed in docs/ANALYSIS_TOOLBOX.md.
All load-bearing scripts remain in scripts/ and are listed in docs/ANALYSIS_TOOLBOX.md.
Do not run scripts from this directory as part of the calibration loop.

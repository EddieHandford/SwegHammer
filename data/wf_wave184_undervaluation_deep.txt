====================================================================================================
INTERPRETATION KEY
====================================================================================================

TABLE 1 — D/T < 1.0 = faction takes more damage than it deals.
  Survival curve: if Me%alive collapses in rounds 1-2 => (1) DURABILITY.
  If Me%alive stays high but D/T remains low => (2) OUTPUT gap.

TABLE 2 — dPrimary large negative => (3) POSITIONING/VP gap.
  dSecondary near zero => secondary scoring is not the root cause.

TABLE 3 — Output ratio < 1.0 = under-shooter deals less per surviving unit.
  ratio ~1.0 + ME unit-rounds << OPP => (1) DURABILITY dominates.
  ratio << 1.0 + ME unit-rounds comparable => (2) OUTPUT/BUFF GAP dominates.

Candidate unmodelled output buffs:
  Astra Militarum Orders: +1 to hit or re-roll 1s to hit, once per Officer
    per Command phase. (Wahapedia: 'Voice of Command'.)
  Adeptus Mechanicus Doctrina Imperatives: +1 to hit (Protector) or
    +1 to wound (Conqueror), chosen at start of each battle round.
    (Wahapedia: 'Doctrina Imperatives'.)

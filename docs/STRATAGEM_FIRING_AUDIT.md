# Stratagem firing audit

Diagnostic generated by `scripts/strat_firing_audit.py` (SwegHammer task #169). Each of the 10 factions plays 10 seeded battles against every other faction; we tally `StratagemFired` events per army and combine with residual CP at battle end to compute utilisation.

Utilisation % = CP spent / (CP spent + CP unspent at game end). A faction below 70 % is leaving CP on the table.

Per-stratagem **rate %** is `fires / games` and can exceed 100 % for stratagems that legally fire many times per battle (e.g. Command Re-Roll triggers on every failed wound, so >300 % rate means ~3 fires per game on average).
